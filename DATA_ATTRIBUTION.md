The source material was **changed** for this release as follows. We sampled and
filtered the BEIR query pools, matched selected questions to FlashRAG reference
answers, retained only records with one unambiguous answer, combined those
fields with generated attacker targets and five ordered passage bodies, and
reformatted them into `qc.json`, `qci.json`, `adv.json`, and `sources.csv`.
Question matching can use Unicode NFC, case, and whitespace normalization and
trailing-question-mark handling; the released question is the selected BEIR
question, while the released reference is the accepted FlashRAG answer. The
selection rules, source revision, and record mappings are preserved in each
dataset's `manifest.json` and `audit.jsonl`. The publication does not claim
that upstream authors supplied or checked the generated targets or passages.

Retain the source attributions, license links, and this change notice when
redistributing upstream text. Apply the relevant upstream license and its
ShareAlike conditions to any reuse or adaptation of that material. Because a
record contains material from several sources, this file does not declare a
single license for the combined record or resolve all downstream uses.
